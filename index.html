01 — Personal project

redSight

An online platform for sharpening your skill at finding bugs in source code.

A personal project that keeps my bug-hunting skills sharp in the age of AI-generated code. I used Claude Design in a structured way, so designs translate cleanly into usable components and workflows in a Next.js application.

Design System

Everything starts with a custom design system, strictly enforced with visual-regression and behavioral tests.

Source Code View

The screen where users read the problematic source code and hunt for bugs. Shown in light and dark mode, with different features toggled in each.

Results View

After submitting the bugs they found (or missed), users see their results here. Shown in light and dark mode.

03 — Ongoing personal project

Stickr Store

A Photoshop- and Figma-inspired editor for designing custom stickers and sending them to print.

An ongoing personal project that has taught me how to push AI-assisted design workflows to their limit. It's a complex build: a full editor for designing custom stickers, connected to a print pipeline.

04 — Client work

UNHCR — Tracks: Life on the Run

Web design, interactive media and infographics telling the story of the Syrian refugee crisis.

Design work for UNHCR, the UN Refugee Agency: the website for “Tracks: Life on the Run”, a documentary about everyday life in the Za’atri refugee camp; interactive sections kept up to date with live data from the camp; awareness campaign websites; motion graphics; and interactive infographics for the UN’s internal newsletters.
